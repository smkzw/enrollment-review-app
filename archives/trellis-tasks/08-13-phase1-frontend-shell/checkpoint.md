## 关键修订与坑点

1. 时间窗最初显示 `undefined`，根因是前端 Wire 类型沿用不存在的旧字段，而冻结 fixture 使用锚点、方向和上下界字段。修复覆盖 Wire、ViewModel、映射、显示和回归测试。
2. `REQ-` 在方案差异区残留，根因是该映射绕过统一的用户显示编号转换。所有规则差异和近期变化现统一显示为“必做-xx”。
3. hash 路由切换后仅等待 `networkidle` 会立即返回，缩放检查曾在旧页或加载页上假通过。现在等待新页面标题、关键内容和加载状态退出后再测量。
4. `body.style.zoom` 不会触发与真实浏览器缩放一致的媒体查询，曾制造错误溢出。现在按物理屏幕宽度换算 CSS 布局视口，模拟 150%/200% 浏览器缩放。
5. 父规则现汇总子项风险；工作台默认落在风险个例和风险组件；今日事项携带规则编号并深链到对应证据；可见文件名和单位均已中文化。
