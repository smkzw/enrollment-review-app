**V4 是本实施材料包的版本，不是新建产品 Phase，也不是要求重写系统。**

## 已由用户明确的三项决定

云端使用无限制；默认处理少数风险、冲突与未决项，随时查看全部条款及原件；日常几十页至一百余页，主要是有手写批注、未必高清的扫描检验报告、病历、手机照片和屏幕翻拍。

延续既有决定：本地单 Mac 单用户工作台，内置前置、相对独立的方案解构/审核 Agent，多 Agent 按职责协作，跨方案通用；取消固定全量双 VLM、每页完整 ClausePack、统一 65K 下限；不猜遮盖内容、不独立判读心电波形/影像或重评分；原件与历史不可覆盖。

## 交给开发 Agent 的顺序

先发送 `01_AGENT_MASTER.md`，同时附上本包。Agent 在当前工作树先核实基线与已有成果，然后按 `03_WORK_PACKAGES.md` 实施。无需再次询问上述三个问题。用户未确认的模型品牌、并发数字、性能门槛，不得写成用户指定要求。

| 材料 | 用途 |
|---|---|
| 01_AGENT_MASTER.md | 可直接发送的主指令、执行顺序、禁区及回交要求 |
| 02_HARNESS_AND_DATA_CONTRACT.md | 新读取策略、图与循环边界、覆盖/事实/判定合同、增量失效 |

本包将上轮“只读讨论”升级为可交付开发 Agent 的实施方案；不把尚未验证的组件说成已经实现。三项用户决定已冻结，其他实现细节由 Agent 在现有框架内按测试证据落地，不另造编排平台。
