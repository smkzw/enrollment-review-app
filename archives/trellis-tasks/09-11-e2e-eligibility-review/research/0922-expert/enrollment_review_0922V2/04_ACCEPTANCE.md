# 0922V2 验收矩阵

下列是待开发Agent在当前真实工作树中执行的验收，不是本轮已经跑通的产品测试。
本包18条离线探针的观察在probes/results.json，支持类型/依赖与资料均为合成。

| ID | 用例 | 合格标准 |
|---|---|---|
| A01 | 项目锁定依赖npm build | tsc和vite均成功；不禁用unused/strict |
| A02 | 默认scale out在源码内 | 可控重定向，不NameError |
| A03 | SCALE_SET_DIR在repo或symlink回repo | 拒绝真实原件落入可跟踪树 |
| A04 | PDF+JPEG+PNG+多帧TIFF+HEIC | 文件/页/帧及unsupported明确；非PDF不计0；实际解码 |
| A05 | 401/403/500、200 error、200 [] | 分别失败；没有静默空报告成功 |
| A06 | 200正确结构但错误subject/snapshot/rule | 拒绝范围错配 |
| A07 | 部分页failed但job completed | 页处置分母完整，不以技术终态宣告全部可用 |
| A08 | 只有合格日期配对、没有合格值 | 不将fact.value投入临床比较 |
| A09 | 值合格，时间窗要求的日期未合格 | 未决并说明date资格缺口 |
| A10 | single下多个观察；有明确排序 | 无规则不合并；有规则按已核实scope采用 |
| A11 | value+date+source均合格正例 | 产生正确可追溯确定结果，不全UNKNOWN |
| A12 | 全配对拒绝、无observation_policy | 不回落旧fact_type猜测 |
| A13 | 空选择/缺证/明确否认 | 三者语义分别正确；缺证不是FALSE |
| A14 | 新无关病例任务数>5>100 | 旧对象选择和结果不受无关任务影响 |
| A15 | 同authority但facts/locator/metadata变化 | 输入digest失效，不沿用过期资格 |
| A16 | 不同组件局部ID冲突试图冻结 | 原全局唯一性检查仍拒绝 |
| A17 | 请求/响应模型名登记别名、未知差异、缺失 | 显式策略；缺失不补成已验证身份 |
| A18 | finish=null/length、流中断、非法JSON | 分别错误；watcher和产品都不报成功 |
| A19 | 规范化failed/cancelled/timeout | 保留失败/暂停状态，非零退出，不假称整链完成 |
| A20 | 单页实际HTTP合同控制变量 | 取得净化回执和具体错误；真正一页通过后放大 |
| A21 | 同gap先低后高及反序 | 组严重性和默认成员均优先最高且顺序稳定 |
| A22 | 两来源同类缺口 | 两独立issue，不因gapType相同一并关闭 |
| A23 | 明确深链、筛选后选择、上一/下一 | 与有效问题集合及显式深链合同一致 |
| A24 | 1920×1080、2560×1440、3840×2160 CSS视口 | 左栏不无限伸长，原件受益；记录实际宽度和可扫描问题行数 |
| A25 | 125%/200%缩放、文本间距覆盖、键盘 | 内容/操作可达、不叠盖、不靠页面裁切掩盖问题 |
| A26 | 无已采用事实，但有候选/有原件 | 能浏览，候选清楚标未采用；首页不假称引用 |
| A27 | 所有revision故意取不同数 | 界面各版本来自对应实体 |
| A28 | 风险→受试者→证据→返回队列 | 对象/节点/来源正确，筛选分页选中恢复 |
| A29 | 同页年龄/身高共享页定位 | 只能为相关候选，不批量改成同一个值 |
| A30 | 同一观察多派生通道的一次更正 | 有据联动或重新推导，必要资格重算，新结果出现，旧不变 |
| A31 | 补证没有引用任何旧fact | 与证据范围相关的未发现结论失效并重查 |
| A32 | 完整单例当前节点 | 每条规则及跨章要求处置齐全；明确正例/反例/未决均正确 |
| A33 | 30/60/120/150页混合资料 | 分别记录预期/处理/核实/可用页、自动与人工耗时，非只报总秒数 |
| A34 | 另一结构不同的方案 | 方案Agent内置解构到审核，未验证就不称泛化已证实 |

## 证据格式
命令、exit code、HEAD、依赖版本、测试输入hash、真实输出、失败信息、测试类型（合成/真实/回放）、
照片/截图对应CSS视口与缩放、上游请求合同版本、原件/报告范围身份。缺任一必要阶段写not_run。
真实材料、密钥、完整临床payload不进仓库。临床gold须人类核对，不按模型输出反向造gold。
保留正确确定结果的正例，不能用回归全部UNKNOWN换安全。阶段耗时含排队、重试、复用、人工等待；
30分钟是既定优化方向，不是截断临床核查的硬超时。工程压测可以合成，临床有效性不可冒充。
