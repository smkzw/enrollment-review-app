# 集中验收包

## 原则
计划内只安排Q1/Q2/Q3三次检查窗口，不新增逐修订测试仪式。真实缺研究者判断可为正确的未决；软件没有完成核对、供应商错误、遗漏页不能借此伪装临床未决。正式采用签字与工作稿可用分开验收。

## Q1：W0–W2 集中合同检查
- 用锁定依赖运行一次`cd frontend && npm run build`；不以根tsconfig/standalone片段成功代替。修同因错误后仅复跑该项。
- 后端选W1/W2现有目标回归，批量补当前缺反例，不全仓追绿。基线14失败需先分类；节点必需字段缺失先核生产合同和fixture，不能关闭assessment校验。
- R2-01/02：只有日期、缺日期、single多值（含同值两条）、全部拒绝、stale、坏载荷、未完成不进入计算；正常完整记录通过；复查/频次/命题/例外保留各自选择结果。工作稿与冻结计算同输入同语义。
- 供应商专用凭据缺失在本地明确拒绝，不回退其他供应商密钥。修复不得删除已有控制项标签或放宽DTO来掩盖编译漂移。
- 技术不合法evaluation不能被补成无源研究者判断；真有书面判断要求的条款保留此模式。
- 新要求范围共同发布或明确零控制覆盖，缺控制不静默发布。恢复不得激活失败/不完整revision。

## Q2：W3–W5 集中跨层检查
- 主OCR/native/局部VLM/人工各自真实来源完整往返，不能仅用policy字符串和self_consistent获得已核实资格。
- 模型身份missing/别名/不符/流内变化，预算length、429、空正文、错误400、修复保真；请求错误与临床缺证分离。
- 若使用OpenCode，产品会话标识在同一逻辑任务重试/格式修复中稳定，不依赖个人安装标识；技术可连接和服务许可适用范围分开。10的合成图不替代真实单页Schema及来源验证。
- 累计Profile不丢早期用药、日期未知不补；版本/浏览/引用三态和动作导航正确。
- 更正同观察真实派生联动、同页不同观察不联动；补证使旧范围否定检索失效；旧报告hash不变。
- 一次必要产品单页适配及小批验证后进入完整试跑，不反复多模型横评。

## Q3：最终场景与证据

| ID | 用户场景 | 通过标准 | 必须保存的证据 |
|---|---|---|---|
| A01 | 直接上传真实DOCX/PDF方案 | 身份/修订正确，官方编号、父子、例外、节点时限和跨章覆盖可追；同草稿预览→核对→发布 | 来源hash、草稿/规则/控制/节点ID、缺口处置、截图、耗时 |
| A02 | 一例多文件资料上传 | 每PDF页/图像帧均有处置，重复上传不重复造事实；版本合法激活 | 原件manifest、处理revision、期望/已处理/未核/失败分母 |
| A03 | 阅读与原件 | 数值/单位/时间/否定/手写归属正确；局部核实有真实记录；无坐标不造精框 | 来源定位、观察/核实身份、抽查表及错误实例 |
| A04 | 累计个例档案 | 病史/事件/用药和时间线不被末轮覆盖；未知、冲突明确 | Profile与事实/事件/暴露来源、前后范围对比 |
| A05 | 完整当前节点判断 | 官方+控制+资料义务完整；确定正负有原文；不全部UNKNOWN、零条款不能成功 | 当前authority、选择材料、要求分母、结果逐条原件核对 |
| A06 | 缺研究者书面判断 | 明确具体条款无法判断、责任方、所需证据；不伪合格/未触发，不反复弹确认 | 原件检索范围、Action与报告对应条目 |
| A07 | 一次更正 | 同一观察及派生更新、无关对象不变、资格重算、新结果可看 | 影响预览、旧新IDs/hash、作业状态、UI操作证据 |
| A08 | 新补证/复查 | 仅受影响链重算，范围性“未找到”失效，旧报告不变，按用户允许的已提供资料范围判断 | supplement/snapshot/context、失效与新报告、旧件hash |
| A09 | 连续工作台操作 | 待处理/全部切换、深链、排序、返回、原件滚动/标注、更正/行动响应均真实 | Ego Lite步骤、错误/空态、截图，非stub |
| A10 | 冻结与导出 | 页面与导出同源、历史引用固定；无授权合法拒绝且工作稿仍可用 | run/report/action IDs、文件hash、发布授权状态 |
| A11 | 泛化与规模 | 第二方案结构、第二例或异形资料；未硬编码病例/药名/阈值；混合媒体数量守恒 | 留出来源、覆盖表、耗时/遗漏/错误采用、未核列表 |
| A12 | 启动/恢复/部署 | 桌面启动不靠开发者手填JSON，重启续跑/取消可控，本地无双驻留；备份恢复隔离验证 | 启动方式/显式配置路径、日志、版本、恢复和原库不变证据 |

浏览器：Ego Lite正式模式，1920×1080、2560×1440、3840×2160；合理桌面缩放包含200%可访问性核查，不要求手机专版。读图事实核验与美学核验分别记录，截图不证明医学正确。
性能：首次方案、读取、核实、规范化、资格、报告各阶段walltime/模型次数/输入输出usage/缓存/失败恢复；服务不返回的指标unknown，不填0。30分钟软目标超出则解释耗时与可用性，不删输入或降质量伪达标。

## 测试数量不是验收分母
Q3运行现有相关后端、前端、API和正式端到端套件，按实际命令/退出码记载。全仓旧分支/模拟专用测试若无关，可列不适用证据，不能默默忽略；与当前写路径共享合同的失败必须处理。
医学核对按每项当前官方/控制要求及全部来源页处置建立分母，不能只统计成功模型响应。没有gold标注时先由工程审阅者回原件核对并保存依据，独立会商按触发规则审阅关键不确定，不能由测试者手写答案替产品产出。

## 退出与保留
记录状态必须分别是：实现完成、离线验证、真实运行、源文件核对、用户可操作、正式签发授权。无证据不打勾。
交付仍有真实医学未决可以通过产品可用性验收，但必须说明；仍有P1/P2工程错误、未验证关键链、输入范围不完整则不能完整交付。
签署若需用户只将真实待批准项一次性呈交，不制造金标/批准记录，不用无授权作为所有开发暂停理由。
