# D001 全文控制期别适用性缺口

## 观察

使用 D001 原始方案只读构建 II 期全文清单后，共得到 1,689 个结构单元，其中 802 个仍为 `UNKNOWN/MIXED`。表 5 的表头及 12 条禁限用药控制全部保留，但当前阶段图不能为这些行提供可发布的 II 期适用性结论。

进一步按章节统计发现，802 个模糊单元的 `heading_path` 全部退化为“（无标题）”。源方案实际具有“合并用药/治疗 → 禁止的合并用药/治疗 → 表 5”等层级；DOCX 使用数字样式 ID，但 `styles.xml` 中保留中文样式名和 `outlineLvl`。当前结构块只保存样式 ID，全文清单又只按样式 ID 是否含 `Heading/标题` 判定标题，因而在 Agent 之前就丢失了上位章节证据。

因此应先修复通用 DOCX 样式元数据和标题路径，再统计真正剩余的期别不确定项；不能让语义 Agent 补偿结构层本可确定的信息。

## 不能采用的捷径

- 不能把未标期别的章节默认解释为 II/III 期共享。
- 不能因某段靠近 II 期标题或命中“筛选、基线、首次给药”等关键词就直接归期。
- 不能把 D001 表号、章节名或具体药物写入系统级规则。
- 不能由发布门禁补猜语义；门禁只负责拒绝未解决输入。

## 下一步通用合同

第一步先恢复 `style_name` 和可继承的 `outline_level`，让标题路径、表题和表格行都能回到真实上位章节。第二步才把仍无法确定的期别适用性作为独立、可回源的语义判定层，至少保留：

1. 当前结构单元与上位章节、表头、脚注、交叉引用的来源片段；
2. 候选期别集合及逐个支持/反对依据；
3. `明确适用 / 明确不适用 / 跨期共享 / 仍待确认` 四类处置，不把待确认压成共享；
4. 与选定项目期别的最终投影结论及系统稳定身份；
5. 人工覆盖或修订时的理由、原结论和影响范围。

## 验收方向

先对 D001 II 建人工矩阵，至少覆盖官方 IN/EX、流程必做项、表 5、复测与结果有效期、结核、妊娠及随机/首次给药锚点。每个矩阵行必须回答：来源在哪里、适用于哪个研究期别、在哪个审核节点检查、需要做什么、需要达到什么、不能发生什么、何种证据足够、何时只能提示后续节点复核。

## 2026-08-24 结构恢复后复测

DOCX 自定义标题已从 `styles.xml` 恢复中文样式名与有效 outline level，全文标题路径不再依赖原始数字样式 ID 的文字猜测。D001 复测结果：

- 3,581 个结构块、1,689 个全文单元，数量均未缩减；
- 表 5 保留表头和 12 条禁限用药行，完整路径为“研究治疗 → 合并用药/治疗 → 禁止的合并用药/治疗 → 表 5 禁止的合并用药/治疗”；
- 旧上下文将表 5 错误归为Ⅲ期，现正确恢复为 `UNKNOWN`；
- `UNKNOWN/MIXED` 由 802 增至 1,433，原因是去除了跨同级章节的错误期别继承，不是条目丢失；
- 224 个仍为“无标题”的模糊单元均位于正文流，其中 209 个是封面、签字、保密声明、目录等首个有效章节前段落，余下为前置表格/列表；表 5 不在其中。

因此结构假未知已经从语义未知中分离，但语义闭包尚未完成。后续 Agent 需通读研究设计、各期方案、流程表、合并用药/治疗、安全性检查、复测/有效期、随机与首次给药要求等全文关系，并为每个适用性结论保留支持、反对和未解决依据。

## 2026-08-25 语义期别解析基础设施验收

结构明确的选定期别、对侧期别和跨期共用单元不再交给 Agent 重判，只把 `UNKNOWN`、`MIXED` 或缺少可接受单期归属的 1,433 个单元交给语义处置。每个结果必须是选定期别、对侧期别、跨期共用或仍待确认之一，并且摘录必须逐字存在于引用的冻结结构单元。

首次真实 D001 规划发现：如果把所有显式单元、流程表及含“筛选/基线/给药”的文本复制给每一批，235 批每批约 171.5 万字符，总计约 4.03 亿字符。这不是模型上下文大小的简单问题，而是检索设计将无关上下文当作全局条件，会同时降低语义精度。现改为全清单索引加目标相关检索，仅携带相关期别章节、访视流程、显式交叉引用、标题邻域及完整同表结构。

复测后 235 批包含 37 个紧凑全局锚点；每批上下文数最小/中位/最大为 36/40/145，字符数为 52,964/61,674/207,886，总计 17,337,795。表 5 虽跨两批，但两批都包含全部 13 个表结构单元，不会因分批丢失表题、表头或其他行的限定。

发布视图只做非变异聚合，必须与当前清单的协议版本、文档哈希、快照、选定期别以及每个源单元的完整内容精确相等。同 ID 但摘录、位置、表格成员或上下文被改动时也必须拒绝。目前只验收了这一基础设施；D001 的 1,433 个模糊单元还没有实际运行语义 Agent，更不能视为 II 期控制目录已发布。
