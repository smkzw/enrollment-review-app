# Phase 5.8b/5.8c 全文控制 Agent 与发布门禁验收检查点

## 已完成

- 全文结构单元按冻结来源顺序和标题路径确定性分批，关键词只影响优先级。
- 每个结构单元在一个批次中且仅处置一次；一个单元可链接多个候选，一个候选也可覆盖多个明确来源单元。
- 新增独立于官方 IN/EX 解构器的其他方案控制 Agent，使用中文原生严格结构化输出和同会话定向修复。
- 候选分别表达触发条件、义务、例外和适用条件四层 DNF，并使用冻结审核节点目录。
- 发布只信任完整的系统水合批次结果；调用者无法用旧 manifest、单一候选链接或独立候选绕过来源闭包。
- 发布门禁覆盖全文处置、表格行、来源、期别、审核节点、时间锚点、义务逻辑、跨来源关系和未解决冲突。
