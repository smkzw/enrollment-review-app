## 9. 深度复盘：纠结与方向

**战略有改善，结果仍未交付。** 已从全方案编译转向真实稿／更正／补证／可视化，产生可回看的版本和用户动作；45无法判定仍不能称可用。不能以“边界严所以安全”合理化不可用，也不能为变绿取消来源或医学逻辑。

**原文与含义。** 引文一样仍可能把标题当条件、治疗期例外挪到筛选、瞬时／回顾或不同季节拼接。正例、等义、反事实和真实消费者一起核，不只Schema或引用。

**泛化与过拟合。** SAR失败用于发现阶段、例外、测量背景、变量、来源角色与布尔依赖的共性缺口是必要；围绕同药／同句加专用提示和恢复函数不可持续。临床阈值和项目词汇留在冻结规则，不进共享代码。D001留出未做，不能声称已证明泛化。
