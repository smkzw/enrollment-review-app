# Worker 01 同会话返修：阻断“整段原文伪结构化”的通用语义缺陷

父级对真实 D001 58 行矩阵做临床语义抽查，发现合同虽然结构合法，却允许以下系统性失败：

- IN-04 的 PASI、PGA、BSA 三个“且”条件被塞进一个原子；
- EX-20h 的“异常 + 有临床意义 + 研究者判断构成不可接受风险”被塞进一个原子；
- “符合以下任一项”“存在以下任何一种”“注：”被当作独立排除分支；
- EX-09 的复测说明、禁用预防药物被误当成与活动性结核并列的排除分支；
- 明确写“筛选和基线”仍只建一个 `EVENT_DATE` 锚点；写“首次给药前3个月或5个半衰期”却可标成 `ON`；
- 所有最低证据都使用“方案官方条件”并复述原文，未说明需要何种病历、报告、评分或研究者判断。

请仅修改已授权合同/矩阵测试路径，建立通用阻断，不得硬编码 D001 编号或项目文本，不得修改 D001 工件。

## A. 条件/义务原子性

1. 增加稳健的顶层连接词检查（忽略成对括号内示例/术语）：单个条件原子或义务原子不得包含顶层“且/并且/同时”或把两个独立谓词连成一个；顶层“或/或者”也应拆成 DNF 替代组，除非是不可分割的术语/对象集合并由来源逻辑说明明确证明。不要用简单全字符串包含导致括号示例误报。
2. 含换行或多个分号的长列表不得作为一个原子。
3. 列表引导语、章节提示和注记标签（如“符合以下任一项”“存在以下任何一种”“以下要求”“注：”）不得作为条件/义务原子。它们可以保留为来源锚点或 DNF 逻辑依据，但不是可判定事实。
4. 当 DNF 有多个替代组或一个组有多个原子时，每组必须有非空 `logic_basis_zh` 和直接来源锚点，明确该组为何是“且”或为何各组是“或”。
5. 多项复合逻辑不得靠 `unexpressed_logic=[]` 蒙混。若来源存在明显顶层连接关系但结构未表达，合同应拒绝；若确实无法表达，必须保留非空未表达逻辑并使严格验收失败，而不是发布。

## B. 时间锚点一致性

1. 扩展现有检查：标签含“筛选”不得使用泛化 `EVENT_DATE`；含“基线”不得使用泛化 `EVENT_DATE`；含“随机/首次给药/首次用药”不得使用 `SCREENING_DATE` 或 `EVENT_DATE`。
2. 标签含“前/之前/以内/内”并明确回溯窗口时不得标为 `ON`；含“后”不得标为 `ON`。允许“筛选时/基线时/当日”使用 `ON`。
3. 同一来源明确“筛选和基线/筛选或基线”时必须保留两个命名锚点或在合同中使用能无损表达多锚点的结构；单个 `EVENT_DATE` 不得通过。
4. 不得把“首次给药前 N 或 M 个半衰期，以较长者为准”压成无上下界的 `ON`；无法完整结构化时应阻断。

## C. 最低证据不得是占位复述

1. 拒绝空泛 `fact_type_zh`，至少包括“方案官方条件”“方案要求”“入排条件”“核对结果”等不能说明证据对象的占位词。
2. 最低证据 `description_zh` 不得与某个完整规则摘录或义务原子逐字相同；必须说明可接受的事实/资料或研究者记录。
3. 官方入排行的 `required_source_types` 不得为空。它们可以是病历记录、既往资料、检验报告、检查报告、评分记录、知情同意书、研究者评估记录等通用临床来源。
4. 涉及实验室、影像、心电图、妊娠检测、量表/评分等客观结果时，最低证据必须声明同期客观来源；不能只靠筛选病历转述。
5. 需要研究者判断的条件，其最低证据必须能表明需要研究者评估记录；不要把所有 `requires_professional_judgment` 粗暴设为 true。

## D. 节点与层次边界

1. 合同不得默认所有官方规则都是“筛选提前关注 + 基线判定”。若来源只命名筛选、知情同意或基线/首次给药节点，审核节点应与命名节点一致；没有来源依据的额外节点必须可被严格校验拒绝。
2. 如无法仅凭现有 `MatrixReviewNode` 做来源一致性校验，增加每个节点的 `source_anchor_ids`，并要求节点名称/阶段能由锚点逐字摘录或规范映射支持。字段变化时升级矩阵合同版本并补序列化测试。
3. 不要把研究 II 期与筛选/基线节点混为一维。

## 验收

- 用最小通用实现覆盖上述失败模式，不硬编码 D001 编号、疾病或药物。
- 新增正反例，含括号内“如 A 或 B”不被错误拆分、顶层 AND/OR 被正确阻断、列表引导/注记被拒绝、错误时间锚点被拒绝、占位证据被拒绝、节点缺来源被拒绝。
- 保留合法简单原子、现有 DNF、候选/正式身份、中文可见层和来源闭包。
- 运行矩阵聚焦及 5.8a-c 相关回归。

完成后报告合同版本、迁移要求、测试结果及仍不能确定性验证的语义边界。
