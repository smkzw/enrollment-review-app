# Worker 02 同会话返修：按 v4 从原文重构全部官方规则与流程控制

父级临床验收判定现有 v2 工件不可接受：虽然条数、标题和来源闭包正确，但绝大多数条款只是把整段原文塞入单一条件/义务，复杂 AND/OR、例外、时间、证据和阶段均未真正结构化。请在同一会话对两个授权工件进行**从原文重构**，不是字段迁移或补丁。

合同现为 `phase5/control-matrix/v4`。不得修改应用合同/测试，不得改原 DOCX。

## 全局语义规则

1. 官方父级仍严格 6 IN + 30 EX，不新建官方子编号。复杂组件只能存在于父行的原子、DNF、例外、时间、节点和证据中。
2. 条件原子和义务原子必须是单一可判定谓词。顶层“且/或”必须拆成多个原子并由 DNF 表达；括号内例子不拆。列表引导语、标题、`注：` 不能成为原子。
3. 入选标准的达标条件应进入原子化义务及其 AND/OR 表达；仅在特定人群适用时才使用 applicability（如有生育能力者）。
4. 排除标准的排除触发条件应进入 `trigger_expression`，例外进入 `exception_expression`；不要把排除条件本身误当成“适用人群”。`applicable_population_zh` 应说明真正适用人群，通常为本项目拟入组参与者。
5. 复测说明、允许措施、禁用预防药物、资料有效期等不等于排除触发分支：若它们不是该官方父条款的触发/例外，不得与触发条件并列为 OR。可以由后续跨章节控制单独承接；当前官方行只保留与其父条款判断直接相关的来源锚点，避免孤儿来源。
6. 每条最低证据必须说明事实对象、资料类型、到期节点和是否要求同期客观来源/研究者评估记录。不得写“方案官方条件”或重复整条原文。
7. 审核节点按原文和研究流程共同决定：原条款明确节点时使用直接锚点；原条款未写节点或需要基线复核时，用同矩阵“入排标准审核”流程行作为 `workflow_basis_row_id`。不得复制流程锚点进官方行。
8. 流程行本身也必须迁移到 v4：节点绑定直接来源，操作、达标/完成要求、时间和最低证据原子化；继续使用流程候选身份。

## 必须逐项深挖的已知失败模式

- IN-01：签署知情同意、良好沟通、理解并遵守要求不是一个原子；保留正确 AND。
- IN-02：年龄下限与上限同时满足；性别不限不是额外阻断条件。
- IN-03：研究者确认斑块状银屑病、病史≥6个月、稳定期同时满足；筛选节点判定。
- IN-04：筛选与基线分别保留节点/锚点；PASI≥12、PGA≥3、BSA≥10% 为三项 AND，不能整段塞入。
- IN-06：先表达有生育能力人群适用性，再表达无怀孕/捐精计划与避孕义务；知情同意起点和末次给药后3个月终点不能压成一个 EVENT_DATE。
- EX-02、EX-08、EX-11、EX-16、EX-20h、EX-21：疾病/异常存在与研究者判断等是明确 AND，不得弱化为单独存在即排除。
- EX-04、EX-09、EX-10、EX-12、EX-14、EX-15、EX-17、EX-18、EX-19、EX-22、EX-25～EX-28：逐条按原文复原 OR、AND 和例外；不能把整句当一个原子。
- EX-09：`符合以下任一项`、`注：` 不是分支；复测说明和“不允许利福平/利福喷丁预防”不是与活动性结核并列的排除条件。
- EX-18：标题行不是分支；各洗脱类别是 OR；每个固定窗口/半衰期规则保留首次给药锚点和实际数值，来氟米特清除洗脱例外单独表达。
- EX-20：各明确阈值是 OR；ALT/AST/TBil 是同一阈值组内 OR；“其他实验室异常”只有在异常 + 有临床意义 + 研究者判断参与研究会构成不可接受风险三项同时满足时触发。
- EX-22：HBV/HCV/HIV/梅毒为 OR；HBV、HCV 各自内部 AND/OR 保真；梅毒特异性抗体阳性例外必须要求非特异性抗体阴性 + 研究者判断既往感染已治愈，绝不能把特异性/非特异性抗体混同。
- 所有“首次给药前 N”用 FIRST_DOSE + BEFORE；“N个月或5个半衰期取较长者”同时保留固定窗口和半衰期倍数，不能用 ON。
- “筛选或基线/筛选和基线”拆成两个命名锚点，不得用 EVENT_DATE。

## 流程项目临床边界

保留的流程行必须确实影响筛选、基线、随机或首次给药资格；建议性照片、DLQI、随机动作、PK/IL-17A研究采样、给药/治疗支持不得回流。对 22 条再次逐项检查：

- “入排标准审核”应准确包含筛选与基线/首次给药前节点，并可作为官方规则的流程依据。
- 客观检验、检查、评分使用报告/原始评分记录，设置同期客观来源。
- 病史、治疗史说明筛选病历记录与既往资料的可接受边界；阳性长期病史仅由筛选转述时保留溯源要求，但方案未要求客观既往证明时不要擅自新增硬性资料。
- 合并治疗记录可作为资格控制信息，但不得把“记录”本身等同于存在禁用治疗。

## 验收输出

1. JSON 可由 v4 合同加载，严格冻结来源/处置/期别/节点依据校验通过；Markdown 由 v4 renderer 生成并通过序列化一致性。
2. 报告按 36 条逐项列出：原子数量、DNF 形态（例如 `(A且B)或C`）、例外、时间锚点、筛选/基线节点作用、最低证据类型。再列 22 条流程项目的节点和证据。
3. 明确列出从官方行剥离、留待跨章节控制处理的复测/操作说明，不得丢失审计线索。
4. 运行 v4 聚焦测试；复核原 DOCX 指纹不变。
5. 任一条无法无损表达时停止并报告具体编号与来源，不得用长文本原子、空泛证据或统一节点模板绕过。
