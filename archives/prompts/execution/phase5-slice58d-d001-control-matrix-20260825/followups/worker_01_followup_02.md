# Worker 01 同会话可见临床语言修订

父 Codex 对修订后的实际 Markdown 进行了可见工件验收。机器英文枚举已隐藏在注释中，但可见正文仍暴露 `pcm-row-*`、`pcm-src-*`、`stage:*`、`proc-*`、`pctrl-*`、DNF 原子 ID、关系行 ID 和来源片段 ID。这不符合面向中文临床试验医学监查人员的工件要求。请继续仅修改 Worker 01 授权的五个文件：

1. 所有稳定身份、源锚点、工作流节点 ID、时间约束 ID、证据 ID、关系 ID、条件/义务原子 ID 只保留在隐藏的机器身份注释/JSON 中，不得出现在可见 Markdown 正文。
2. 审阅索引不显示“行身份”。官方入排显示方案官方编号；流程必做项显示“流程必做 01”类中文顺序标签；其他章节控制显示“方案控制 01”类中文顺序标签。稳定 ID 继续隐藏保留供校验。
3. DNF 逻辑必须以对应条件/义务的中文表述展示，用“（A 且 B）或（C）”形式保留且/或关系，不显示原子 ID。
4. 审核节点只显示中文节点名、阶段、作用和顺序；最低证据只显示中文事实类型、说明、应于哪个中文节点取得、来源类型和证据强度要求。
5. 跨章节关系的目标用目标控制的中文显示标签+短标题，不显示行 ID。来源闭包可见正文显示来源标题路径、人能理解的原文位置和逐字摘录；内部 source/span/anchor ID 仅隐藏保留。
6. `required_action_zh`、`attainment_criteria_zh`、`prohibition_zh` 应允许结构化空值，但一行至少有一项来自方案的实质性内容，且 `obligations` 仍是权威逻辑。渲染空值时显示“方案未规定该类要求”，不得要求生成者填写“无额外要求”等伪于原文的占位义务。
7. 增加可见文本回归：剔除 HTML 注释后，不得包含上述稳定 ID 前缀、英文枚举值或内部字段名；同时证明 JSON/Markdown 的隐藏身份和顺序仍一致。
