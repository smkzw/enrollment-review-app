So a `REQUIRED_PROCEDURE` unit with a typed temporal gap and only `additional_requirement` review items is now retained whole-unit non-executable; previously it was refused by the whitelist. Counterexample input: correspondence path untouched, error class `{"TEMPORAL_SCOPE_UNRESOLVED"}`, one procedure unit, all review items `additional_requirement`, full literal coverage — output is a `RESTRICTED_SOURCE` unit, no candidates, no `independent_scope_proof`. If unintended, the minimal tightening is to allow `additional_requirement` only when the unit also contains a genuine unresolved review item (`uncertain_indexes ∩ set(indexes)`), leaving the temporal allowance to be added deliberately with its own test.
