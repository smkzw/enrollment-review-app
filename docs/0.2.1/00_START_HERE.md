# 0.2.1 START HERE

## 这是什么

入排审核子系统 0.2.1：0.2 系列的收敛冲刺。自 2026-10-17 起替代 0.2.0 的全部计划、进度与交接文档（已归档到 `archives/0.2.0-docs/`）。

0.2.0 打通了真实工作稿、真实更正与补证，但没有通过验收：问题卡片等于全部条款，用药项全部无法判定，重算偏慢，计算逻辑在两个病例上反复改版却没有准确率度量。0.2.1 不加新功能，只做收敛清单，目标是先通过场景门槛（G1），再与人工 IE 表对照（G2），最后在 D001 上验证换方案（G3）。

开发方式也变了：Codex 在 Orca 终端中作统筹，把实现任务派给 OMP（多模型）和 CodeBuddy 执行节点，自己负责审查、合并、真实数据运行和向用户汇报。
