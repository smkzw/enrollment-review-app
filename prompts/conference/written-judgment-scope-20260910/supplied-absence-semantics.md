# C03 bounded semantic review: absence in submitted materials, not universal absence

Same primary zcode/GLM-5.3:max, no fallback. Read-only text-level design review; no raw images needed, no claim of visual capability. No code/doc/data writes outside returned report, no other agents, network, credentials, clinical database operations or local services.

Original explicit user requirement: "如果两个模型都判定为缺失研究者书面判断的具体条目，不需要停下来让用户再确认。因为这可能就是入排审核需要报告的内容，在后续的入排审核结果中进行说明即可，如‘在某某条的入排审核标准中，由于缺少研究者的判断，所以无法判定是符合还是不符合。’" Other active boundaries: report missing source file/unperformed procedure/professional judgment/conflict/OCR risk separately; failure or unreadable cannot become absence; no automatic acceptance of ambiguous excerpts. Product reads current-node supplied evidence, cannot prove an external record never existed. Source files are immutable, later-node evidence must not rewrite earlier-node conclusion.

Inspect current recovery plan section2, written_judgment_evidence.py, fact_expectation_gaps.py, contracts/evidence_expectations_v2.py, judgment_search.py and judgment_search_coverage.py, and candidate reader v4. Question: existing implementation deliberately leaves source_scope_verified=False because a frozen upload manifest cannot prove all external clinical records have been supplied. Does demanding that impossible universal proof before any professional_judgment gap over-constrain the user's requested workflow? Specify a minimal source-bound rule for reporting ONLY "本次提交的资料中未见与该项要求对应的研究者书面判断，因此暂无法判定" without claiming judgment never occurred, procedure unperformed, or eligibility satisfied.

Propose exact conditions and ordering: requirement genuinely needs written assessment (not every numeric test); applicable current due-stage verified; all current snapshot supplied pages searched by two independent completed readers against the same published target/version with no missing/failed/unreadable/ambiguous related channels; found/mixed candidates block absence pending applicability review. Distinguish known missing required source document (missing_source_file remains, do not relabel as professional judgment alone) from fully read submitted materials lacking written assessment. Existing contract all_supplied_pages_searched_without_candidate can remain descriptive; no caller-set universal-complete Boolean needed. Clarify whether gaps may coexist without duplicating user actions, using existing structures, not inventing another certification framework.

Challenge the proposal with counterexamples: incomplete upload, unknown author, report copied into screening chart, relevant later-node record, generic "符合入排" statement, explicit missing required report, all pages readable and no written judgment. Do not solve using default modes/fact_type guess/date borrowing or forged complete flags. Provide smallest integration and test matrix, mark material unresolved choices. Do NOT implement, do NOT assert new user approval, do NOT ask user to confirm a documented missing judgment contrary to their instruction. Evidence-bound clinical review is not formal project signoff.
