门禁现在把传入的全部 `units` 写入 `structure_unit_ids`，不再只写条件句所在单元。消息仍包含完整条件句。`_source_units_for` 按候选的 `frozen_structure_unit_ids` 逐个取单元，缺一即失败，不会静默丢掉单元。合成测试传入 `su-single-conditional` 和 `su-dependent`，期望的结构单元是 `("su-dependent", "su-single-conditional")`，并要求消息含「若A阳性，则进行A检测」。`publication_repair_error` 在单元列表非空时原样把该列表用作修订范围，不会再缩成子集；本轮只额外把 `issue.message` 放进每条发现。

定位键由 `_located_publication_failure_identities` 按发现单独生成。`repair_scope_unknown` 时返回空元组。其余发现只有同时具备能映射到当前线序的 `entity_id`、非空结构单元、`json_path` 和字符串 `message` 才入键。键内容是候选序号、错误码、路径、结构单元、来源跨度和整段消息的 `_sha256`。无路径或无单元的发现被跳过，不会清掉旁边已定位的发现。运行器仍保留原文 `sha256 + error.code + str(validation_error)[:2000]`，并在任一已定位键第二次出现时停止。定位键使用的是完整 `validation_error`，不是收窄后的 `repair_scopes[0]`。

合成反例与上述定义一致。`extra_unlocated=True` 时，旁路消息写成「其他问题第N次」，位于缺陷的消息保持「同一原文条件未对应」；标题变化会改变候选身份和原文哈希。`corrected=True` 时第二次校验直接通过。长条件测试用「共同原文」重复 600 次再加「条件甲」或「条件乙」，并比较 `candidate-a` 与 `candidate-b` 的键。显式历史测试覆盖原文、长度、哈希、已解析却缺原文，以及 `transport_failed` 且原文为空。嵌套测试仍覆盖缺失、重复、改字和外来角色，并确认入参字节不变。深析检查点测试把带哈希和长度的私有历史写入顶层后再读回。

嵌套恢复在共用核对之前就要求原答必须是字符串，且长度和哈希一致。`outcome == "transport_failed"` 且原文为 `None` 的豁免只写在后面的共用循环里。因此显式顶层历史可以保留无原答的传输失败；嵌套旧账走到这里会先抛「来源疑问的历史原答与回执不一致」。

无关测试只删了 `response_kind == "additional"` 那一段未定义引用。版本字面量只增加了 `located-publication-recovery/v1`。

## 推断

上一轮的修订收窄已消除。条件句仍在反馈里；修订授权是候选的全部冻结单元，不是只含该句的单元。

上一轮的指纹作废已按给定反例消除。同一已定位缺陷在候选身份改写、旁路无定位发现、消息前 2000 字相同但全文不同、以及同来源的另一个候选序号下，都有独立稳定键。相同原文哈希的旧停机仍然保留。

仍必须修：嵌套传输失败不能没有原答。

反例：检查点没有顶层 `source_scope_question_history`，`run_result.attempts` 里有一条 `outcome` 为 `transport_failed`、阶段为 `source_scope_question_recheck` 的记录，对应 `attempt_raw_outputs` 的 `role` 为空且 `raw_output_text` 为 `None`。`_saved_source_scope_question_history` 在 3811–3815 行拒绝它。把同一条记录直接放进顶层 `source_scope_question_history`，3822–3823 行会放行。新测试没有覆盖前一种形状。已解析记录缺少原文仍然会失败，这一点成立。这里不能改成返回空历史。

## 建议

嵌套恢复遇到「原文是 `None` 且 `outcome` 是 `transport_failed`」时，按无原答保留该条，再进入共用循环。已解析或其他结果缺少字符串、长度不符、哈希不符、匹配行不是恰好一行，仍应失败。

## 不确定性

这些通过数和预检计数都是所有者报告。本轮没有执行测试，也没有读私人证据，不能证实最新全窗或临床验收。

以下边界不是上述反例的失败：`repair_scope_unknown` 仍会放弃全部定位键；线序对调会改变候选序号；候选身份无法从线序导出时，只剩原文哈希；同函数里「分支复用」和「后果未绑定」仍不产生定位键；显式空列表不会回退去读嵌套尝试，损坏账本则仍会拒绝。
