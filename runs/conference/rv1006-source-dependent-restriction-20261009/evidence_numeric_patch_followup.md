### Severity-ordered findings

**M1 (identity/recovery).** Exact identity comparisons at execution 3964 and 3991 reject pre-patch artifacts while the reuse path (3176/3588) tolerates and re-stamps. Counterexample: a pre-patch `deep_failure_diagnostic` for a numeric-failure batch resumes today only if its `component_identity` carries the new validator token; otherwise 3981-4000 hard-fails, or the partial wire is discarded at 2815-2822. Smallest remedy: tolerant comparison + prior-version stamping at 3964/3991 (or an explicit statement that pre-patch diagnostics resume seed-only). Needs the owner's branch receipt.

**M2 (response contract robustness).** The four-field patch can delete the comparison it exists to repair. Counterexample: `{"evaluation_patch":{"determination_mode":"semantic","operation":null,"predicate":null,"operand_attribute":null}}` — merge 6813-6853 accepts (all other fields unchanged), spec validator 62-69 accepts a semantic spec, and the wire passes. Today the failure is caught downstream: `validate_candidate_alignment` 846-873 requires a predicate when the source has one number and one direction (raised as `CandidateNumericAlignmentError`), and the candidate-hash change forces a fresh alignment. So this is a defense-in-depth gap, not an accepted-harm path. Smallest remedy: when the trigger is `numeric_predicate_missing`, require the merged evaluation to remain a coherent deterministic `value_comparison` with a predicate (or at minimum add the downgrade counterexample test asserting fail-closed and preserved original wire).

**L1 (normalizers).** `_normalize_absent_time_bound_flags` (1211-1227) and `_preserve_unstated_observation_selection` (1230-1267) mutate the copied frozen atom **before** the numeric equality checks (6826-6853). Smallest remedy: apply the same normalizers to the comparison baseline, or skip them in the patch path.

**L2 (tests).** Missing-key patch and patch-path duplicate-source-fields are untested; the extra-key case does not cover schema `required` enforcement (though merge enforces it). Smallest remedy: two parametrized cases.

**L3 (capability detection).** `atom_reader = patch_reader if callable(...) else continue_atom` (9786-9787) means a stub `continue_numeric_predicate` that raises turns a repairable failure into an unrepaired one (returns original wire) rather than falling back.
