## 仍未解决 / 仍存在 P0 问题### P0 — 阻塞当前节点核对工作
1. **"原始识别"与"校对后文本"两个面板视觉完全相同**
   - 操作路径：进入证据工作台 → 中栏顶部。
   - 页面事实：两个 `.evidence-text-pane` 元素的 `background-color` 都是 `rgb(251, 251, 250)`，`border` 都是 `1px solid rgb(214, 220, 226)`；h5 标题颜色、字号、字重完全一致；h5 旁没有 "原始识别 / 未校对"、"校对后文本 / 当前有效" 等状态 chip。
   - 实际影响：监查员在两个完全同质的卡片之间靠位置分辨"系统识别"还是"已校对定稿"；视觉信息密度低，且与左侧的 "当前有效" 状态标识存在冗余/分散。
   - 系统级建议：给 `evidence-text-pane--effective` 增加左侧色条（绿色3-4px）或背景色（淡蓝 /淡绿），并在 h5 旁加 `未校对` / `当前有效` chip。

2. **快捷入口跳转 `原件定位` 后目标区段仍未进入视口中心**
   - 操作路径：进入证据工作台 → 中栏快捷入口 `原件定位`。

   - 实际影响：监查员以为已跳转，实际看不到内容；多次点击 `原件定位` 会得到同样卡顿。
   - 系统级建议：跳转时将目标区段顶部对齐到 `scrollTop = section.offsetTop - smallOffset`，而不是固定值；同时考虑把定位清单默认折叠、跳转后才展开，或在展开态用虚拟滚动。

3. **"原件定位"区段展开后 1973px 高，单页12 项全部展开几乎无法整体浏览**
