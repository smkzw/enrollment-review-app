# Phase 1.5 用户验收预试与返工

## Goal

让 `contracts/v1/interaction/UAT_PHASE1.md` 中 14 项任务在真实浏览器里均可由用户实际操作，并完成正式用户试用前的构建者预试。预试只证明“具备试用条件”，不得替代不少于 10 名目标用户的正式 UAT，也不得据此进入 Phase 2。

## Requirements

- 以正式 UAT 合同为唯一任务清单，不以场景元数据、页面存在或自动化用例数量代替任务完成。
- 补齐当前仅标注为 `prototypeOnly` 但缺少真实交互的项目创建、方案草稿比较/保存、人工确认、批量范围确认和任务恢复。
- 原型动作只修改浏览器本地演示状态，必须使用自然中文说明“本次试用数据仅用于体验操作”，不得伪装成真实 OCR、审核或后台持久化。
- 14 项任务均建立“入口、操作、预期结果、证据、当前缺口、复测结果”的覆盖矩阵。
- 关键证据从规则或风险入口到正确文件、页码和定位精度可见不超过 3 次操作。
- 1280/1440/1920、代表性窄屏及 100%/150%/200% 缩放下，不得出现页面级横向滚动、文字覆盖、主要操作裁切或状态误读。
- 所有面向用户的文字使用中文临床试验语境，不出现 Agent、schema、pipeline、provider、log、fixture、prototypeOnly 等内部术语。
- 预试发现任何预期外临床状态、错误实体、证据缺失或交互断点时，先追查数据、投影和交互链路根因，再修正共享机制。
- 保留正式 UAT 的原始记录模板、错误分类和停止条件；自动化结果与构建者预试记录单独存放。
- 正式任务卡必须写明固定起始页面、受试者代号、行动类别、规则编号和批量对象；不得用“指定对象”占位，也不得把成功答案写进参与者任务文字。
- 每名参与者开始前，记录人员可以用一个中文入口恢复全部合成示例的界面试用状态；该操作只移除本系统 `eligibility-review:uat:` 前缀的会话状态，不影响其他浏览器数据。
- 系统帮助页显示稳定的中文页面版本，任务记录表可直接照录；版本变化后不得与旧批次混算。
- 提供记录人员准备清单、14 项任务的固定起始地址和批次汇总表，避免临场口头提示污染“无辅助完成率”。
- 正式试用记录不得依赖记录人员手工编辑 Markdown 或自行计算 140 次任务运行；提供独立的中文记录工作台，自动保存逐人逐任务原始记录、计算门槛并导出可审阅文件。该工具不得改变参与者原型页面或把自动化结果混入真人记录。
- 记录工作台必须支持建立批次、增加参与者、14 项任务逐项计时、完成/提示/错误分类、操作数、关键证据操作数、原话与异常记录；错误结论必须醒目触发停止提示，不能被汇总平均掩盖。
- 记录工作台自动读取当前界面试用版本；每次界面试用复位不得清除记录数据。记录人员可导出 Markdown、CSV 和本机备份文件，并能从备份恢复，避免浏览器状态丢失造成整批记录报废。
- 不进行安全性测试，不进入数据库、真实 OCR/LLM 或后台核心实施。
- 每轮复测后清理可再生缓存、过时截图和冗余原始日志，只保留可审计摘要与最终证据。

## Acceptance Criteria

- [x] 14 项 UAT 均有逐项覆盖矩阵，且无“仅页面存在”冒充“任务可完成”。
- [x] UAT-P1-02、03、10、11、12 的本地原型交互可以完整执行并可复位。
- [x] UAT-P1-01 至 14 的自动化预试全部通过；主路径无控制台错误和页面级横向滚动。
- [x] 关键证据路径操作数均不超过 3 次，证据文件、页码、摘录和实际定位精度同时可见。
- [x] 真实浏览器视觉复核覆盖桌面、窄屏和三档缩放，未发现裁切、覆盖、误导性状态或内部术语。
- [x] 生成可直接交给目标用户的中文试用入口、逐项任务卡和记录表。
- [x] 任务卡不存在“指定受试者/指定行动/指定父规则”等未解析占位；记录人员无需解释目标对象即可开测。
- [x] 系统帮助页可两步确认恢复全部界面试用状态，完成后回到今日工作，并显示可记录的页面版本。
- [x] 复位只清除允许的界面试用键；其他会话数据不受影响，取消确认时不发生变化。
- [x] 提供可直接汇总不少于 10 名参与者、140 个任务运行的批次表，并保留失败、无效运行和错误结论停止记录。
- [x] 记录人员可在浏览器中完成逐人逐任务记录，无需编辑 Markdown；刷新后记录仍在，参与者界面复位不影响记录。
- [x] 汇总页自动计算有效参与者、有效运行、总体/逐任务无辅助完成率、错误结论、关键证据操作数与主观评价，并明确哪些门槛尚未达到。
- [x] Markdown、CSV 与备份文件导出内容均来自同一原始记录；备份恢复后统计结果一致。
- [x] 当前任务最终状态仍明确标记“等待用户正式 UAT”；父任务仍停在 Phase 1.5，未启动 Phase 2。

## Notes

- 正式冻结要求仍按 `UAT_PHASE1.md`：不少于 10 名目标用户、无辅助完成率不低于 90%、错误结论为 0、用户明确批准核心信息架构和术语。
- 本任务是 Phase 1 返工与 Phase 1.5 预试，不替代用户批准。
