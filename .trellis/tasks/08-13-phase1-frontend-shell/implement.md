# Phase 1 实施步骤

1. 建立 TypeScript/Vite/React 目录、测试与浏览器验收配置，固定开放源代码依赖和锁文件。
2. 建立 fixture stub API、领域到中文 ViewModel 转换和 10 类 UAT 场景数据。
3. 实现响应式全局壳、无登录导航、今日工作与项目看板。
4. 实现 Patient Profile、证据覆盖泳道和事件/规则/证据联动。
5. 实现入排三栏工作台、父子规则树、判断/行动/差异与证据定位精度。
6. 实现行动中心、任务详情、快照/ReviewRun 差异、报告、方案入口和详细帮助。
7. 完成单元/组件测试、Playwright 交互与 1280/1440/1920/窄屏多缩放视觉 QC。
8. 修复发现的共享根因，清理缓存与过时制品，提交独立 checker 验收。

当前状态：Phase 0.5 已由同一独立 checker 接受并归档；Phase 1 不建设数据库、真实 OCR/LLM 或 legacy 写路径。
