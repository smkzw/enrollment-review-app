# Phase 1.5 多模型医学监查员角色验收

## Goal

由多个相互独立的模型带入“懒惰、视觉敏感、不熟悉电脑与 AI，但临床试验经验丰富的中文医学监查员”角色，在真实浏览器内自由探索 Phase 1 可交互原型；审查临床信息表达、证据链、规则层级、Patient Profile、页面美学与操作负担，追查预期外结果的系统根因，完成修订复测后决定是否具备进入 Phase 2 的条件。

## Requirements

- 用户不参与本轮试用；不得再以“等待用户真人 UAT”为停止理由。
- 测试者彼此独立，不共享前一测试者的推理或结论；Codex 只向其提供相同的来源、角色、范围和验收条件。
- 测试者必须使用真实浏览器进入正在运行的本地系统，自由探索而非只核对截图或 DOM；允许在合成演示数据中创建、修改、复位项目和受试者相关界面状态。
- 重点体验今日工作、项目看板、方案解构、受试者个例全景、Patient Profile、规则工作台、证据回源、行动中心、批量范围、报告、任务恢复和帮助路径。
- 从医学监查员视角检查：能否快速识别各审核节点结论、明确障碍、证据不足、需研究者判定、溯源提醒、后续阶段复核；父子规则和 AND/OR/例外是否不易误读；证据能否回到文件、页码、原文与定位精度。
- 从 Patient Profile 视角检查：首屏是否优先呈现入排相关、异常、临界和趋势；疾病历程、既往史、合并用药/治疗、检查评分、关键日期、来源和潜在入排风险是否可按时间与主题快速理解。
- 从中文产品视角检查：文字必须是临床试验场景下的中文原生表达，不出现 Agent、schema、pipeline、provider、log、fixture、Gate 等内部词，不用“xx门”“xx信号”等翻译腔或程序员标签。
- 视觉审查参照 `kangzhe-design` 的 `site` 轨：浅色站点、稳定全局导航、多页互通、跨页下钻、康哲暖色身份、风险红仅用于风险；优先信息层级、证据可读性和操作效率，不把系统做成营销页。该轨用于美学与站点信息架构，不覆盖已批准的 React/FastAPI 技术架构。
- 检查桌面 1280/1440/1920、窄屏和 100%/150%/200% 等效布局；不得以固定宽高或缩小字号掩盖溢出、裁切和无效留白。
- 每个预期外结果必须追查到共享合同、合成数据、投影、组件、样式或阶段边界；不得只修单个受试者、单条规则或单个页面的表象。
- 不做安全性、权限、渗透或多用户测试。
- 不读取工作区外真实临床资料，不修改旧项目或 legacy 临床结果。
- 当前 Phase 1 是合成数据原型。测试者必须分别列出“当前真实验证到的能力”和“Phase 2-8 尚未实施的能力”；不得将真实方案解析、OCR、临床事实抽取、模型审核或真实 Patient Journey 处理写成已经通过。
- 用户点名的模型若不在最新全局路由清单中，不得伪装调用或强制绕过；按正式路由执行并记录实际 provider、model、session、fallback 与终态。
- 首次启用每条正式路线先做连通性诊断，再允许一次真实任务尝试；诊断失败本身不触发随意 fallback。
- 长任务保持同一会话并使用最长 120 分钟硬等待；不因延迟重复派发，不进行固定间隔控制器轮询。
- 每轮只保留最终截图、精简报告、可复现路径和决定记录；清理可再生缓存、过时截图与大体积原始输出。

## Acceptance Criteria

- [x] 至少完成一条独立视觉/交互路线和一条独立临床逻辑/证据路线；每条都有真实会话、实际模型和终态证据。
- [x] 测试者在真实浏览器中覆盖 14 项正式任务及自由探索，不以源码静态审查或页面能打开代替端到端体验。
- [x] 每个测试报告分别列出已验证能力、尚未实施能力、阻断问题、重要问题、建议和可复现证据。
- [x] 所有发现经 Codex 复现、去重、分级并定位共享根因；不采纳无法复现或与阶段边界冲突的建议。
- [x] 当前阶段范围内的阻断问题全部修复，并由独立新鲜上下文复测通过；不能在本阶段解决的内容已准确落入 Phase 2-8，而非留作模糊待办。
- [x] 真实浏览器无页面级横向溢出、主要内容裁切、文字重叠、明显无效留白或状态误读；关键证据不超过 3 次操作可达。
- [x] 可见中文无内部实现词、翻译腔和错误临床语义；规则父子层级、阶段状态、证据定位精度和行动责任清楚。
- [x] Patient Profile 能让测试者快速看出主题、时间、来源、异常/临界/趋势和入排关联；任何空白或缺失不伪装成阴性事实。
- [x] 确定性测试、生产构建、全量 Playwright 与最终截图视觉复核通过，且没有用自动化代替角色验收。
- [x] Codex 形成“可进入 Phase 2”或“继续停在 Phase 1.5”的明确裁决，并写明证据与剩余风险。

## Notes

- 本任务取代旧任务中的真人试用执行路径，但不抹除旧任务技术准备和记录工具的历史证据。
- 通过本任务只表示 Phase 1 信息架构与交互原型获得代理医学监查员角色验收；不表示真实临床审核能力已经实现。
