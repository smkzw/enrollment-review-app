## 回滚点

1. 每个迁移前用 SQLite backup API 备份并校验；失败恢复旧库。
2. 每个切片独立提交；发布事务失败不改变当前 RuleSet revision。
3. Agent/解析器候选依赖在隔离环境 spike，通过后才锁定；拒绝后完整清理。
4. 前端新工作台使用 V2 路由，不替换 legacy 只读参照页，直至 Phase 3 验收完成。
