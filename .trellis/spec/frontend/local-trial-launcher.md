# 本地界面试用启动规范

## 1. 适用范围

当 V2 前端以预构建页面供本机界面试用时，桌面入口必须让参与者双击后直接打开系统，不要求输入网址、运行 npm、理解端口或判断终端日志。本规范不适用于 Phase 2 真实后台服务。

## 2. 命令签名

```text
zsh scripts/start_v2_uat.sh
zsh scripts/stop_v2_uat.sh
```

桌面入口：

- `启动入排审核系统.command` 调用 `scripts/start_v2_uat.sh`；
- `停止入排审核界面试用.command` 调用 `scripts/stop_v2_uat.sh`；
- 成功后自动关窗，失败时保留中文提示供记录人员查看。

## 3. 运行合同

| 项目 | 合同 |
|---|---|
| 页面来源 | 只提供 `frontend/dist`，启动时不构建 |
| 页面服务 | `/usr/bin/python3 -m http.server`，不依赖 Node/npm |
| 服务标识 | `GET /uat-status.json` 的 `service` 必须为 `enrollment-review-v2` |
| 页面版本 | `pageVersion` 必须与 `UAT_PAGE_VERSION` 一致 |
| 默认端口 | 从 4173 开始顺延查找空闲端口 |
| 可复用服务 | 仅复用 PID 文件、进程存活、端口监听 PID 和服务标识全部匹配的本启动器服务 |
| 浏览器 | 成功后打开实际选定端口的首页 |

测试环境变量：`V2_UAT_DIST_DIR`、`V2_UAT_STATE_DIR`、`V2_UAT_PORT`、`V2_UAT_PORT_SCAN_COUNT`、`V2_UAT_NO_BROWSER`、`V2_UAT_HEALTH_TIMEOUT_SEC`。

## 4. 校验与错误矩阵

| 条件 | 行为 |
|---|---|
| `dist/index.html` 缺失 | 中文说明缺少试用程序文件，不启动服务 |
| `dist/uat-status.json` 缺失 | 中文说明版本不完整，不启动服务 |
| 端口被其他服务占用 | 不复用、不结束占用方，顺延端口 |
| 未登记服务返回相同标识 | 仍视为其他服务，不得误复用 |
| 本次新服务未通过标识检查 | 仅结束本次明确创建的进程，移除 PID 文件并提示失败 |
| 停止时归属校验任一项不符 | 不结束任何进程，提示联系管理员 |
| 重复停止且没有 PID 记录 | 视为已经停止，返回成功，不要求用户排错 |

## 5. 正常、边界与错误案例

- 正常：4173 空闲，启动后返回正确标识并打开首页；再次双击复用同一 PID。
- 边界：4173 为开发服务，正式试用改用 4174；开发服务不受影响。
- 错误：某服务伪造同一 `service` 标识但没有有效启动记录，启动器不得把它当成正式试用服务。

## 6. 必须执行的测试

1. `bash scripts/test_start_v2_uat.sh`：首次启动、重复启动、普通端口占用、未登记同标记占用、全部占用、缺少构建产物、缺少标记和重复停止。
2. `npm test`：验证源标记字段、中央页面版本和构建标记一致。
3. `npm run build` 后再运行启动器冒烟，核对页面标题与标记。
4. 至少一次 Finder 真实双击启动和停止，核对浏览器打开、PID 清除及端口释放。

## 7. 错误与正确实现

错误：只要端口能访问或能返回同一静态标记，就认定系统已在运行。开发服务器或其他静态服务会被误当成正式试用入口。

正确：只有本启动器记录的 PID、存活进程、监听 PID 和 V2 标记全部一致才允许复用或停止；其他占用一律顺延且不干预。
